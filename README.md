# Index Territory — Asset-Backed 3D Economic Strategy 

Welcome to the official repository of **Index Territory**. This is a closed-loop economic ecosystem built around a first-person (1st-person) 3D strategy game and a live. 

We operate on the **Build in Public** principle. While the game client and art remains proprietary, this repository serves as the transparent core of our tokenomics, mathematics, and public treasury allocation.

---

## Core Pillars of the Ecosystem

**The Closed Club (1st-Person 3D Strategy):** A high-stakes, realistic economic simulation where players execute strategic actions, cooperate, and deploy assets. 

**Treasury-Backed NFTs:** The core game assets are backed by a real, publicly visible Crypto Fund (Treasury). The Treasury infuses tangible value into the world's economy.


---

## The Treasury & Skin in the Game

We don't rely on speculative "hype-printing." The economy is backed by a dedicated Crypto Fund that is regularly funded and expanded by the creator. 

* **How it works:** Game assets (Factories, Lands, Nodes) claim a yield or value from this pool based on mathematical models and active gameplay verification. No one can arbitrarily drain the treasury — it is programmatic.
